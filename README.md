# Post the Meme, Win the Feed — entry repository

A make.fun program/v1 entry for `u-myronera-post-the-meme-win-the-feed-2de960bf`.

- `POST.json` — the X post this entry names (placeholder until the human posts).
- `main.ts` — Node 22 stdlib-only entrypoint: copies `POST.json` to `/output/POST.json`.
- `tools/render_image.py` — Pillow script that renders the meme in-session.
- `entry.png` — the rendered meme to attach to the post.
- `POST_TEXT.md` — prepared post text with `@_myronera` and play code `makefun-mesa-lettuce-popcorn`.
- `STRATEGY.md` — deliverable, scoring, hard caps and the plan to maximise score.

The scored entry is the public X post, not this program. See `STRATEGY.md` and
`POST_TEXT.md` before posting; no upload, post or submission is made by this build.
